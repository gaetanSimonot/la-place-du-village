## Mécaniques en place

### Cache & SWR
- 3 niveaux : SWR mémoire client → CDN Vercel → DB Supabase
- `SWRProvider` global (revalidateOnFocus, dedupingInterval 5000, keepPreviousData)
- `authedFetcher` opt-in pour les routes PERSO (Bearer + refresh 401 + retry max 1)
- `authedFetch` pour les écritures (renvoie Response, caller check `res.ok`)
- Routes regroupées (~13 → 1 fetch) : `/api/hub`, `/api/agenda`, `/api/annuaire`, `/api/annonces/public`, `/api/posts/mur`, `/api/messages`, `/api/people`, `/api/favoris`

### Navigation
- `useSmartBack(parentPath)` sur 15 pages — pas de sortie d'app
- Intercepting routes `(.)producteur/[id]` et `(.)etablissement/[id]` dans `@modal` slot
- Miroir URL via `history.replaceState` (mode, cat, quand, ann, prodcat, q)
- `NavigationHistoryContext` pour tracker la nav interne fiable

### Sécurité
- `requireAdmin` sur toutes les routes back-office (cleanup, evenements/[id], feedbacks, doublons, inbox, prompts, sources, config, zone)
- Rate-limit sur tools publics (autocomplete 100/h, geocode 30/jour, voice_edit 20/jour)
- `escapeLikePattern()` pour la comparaison admin_emails (anti LIKE-injection)
- Détection admin case-insensitive (aligned avec SQL `is_admin()`)
